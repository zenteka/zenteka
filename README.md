# Hi, I'm Karol 👋

Scientist and software/data engineer (PhD in Bioinformatics, UNIL).
I build data platforms and pipelines end to end.
I support my work with Claude or my local AI coding agents.

### Main work
**[HiCverse](https://hicverse.unil.ch)**, a production data platform for 3D genomics:
1,000+ harmonized Hi-C datasets, Parquet data lake (6 TB+), FastAPI, Angular, Docker, CI/CD.
The code lives in the CSO Lab (UNIL) organisation and becomes public with our preprint.
Live demo: [hicverse.unil.ch](https://hicverse.unil.ch)

### Also
- Self-hosted infrastructure: two nodes (CH + PL) on Tailscale, local LLMs, family services
- Earlier: neuroscience and synthetic biology (lab instruments, optogenetics)

### Stack
